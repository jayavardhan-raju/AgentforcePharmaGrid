# AgentforcePharmaGrid

Agentforce Grid–driven inter-store inventory transfers for retail pharmacies, with DEA Schedule II compliance, cold-chain enforcement, near-expiry exclusion, and a full audit trail — all native to Salesforce.

---

## What Is AgentforcePharmaGrid?

A Salesforce DX project that delivers a complete inter-store transfer (IST) workflow on the Agentforce Grid. The pharmacy ops team sees a Grid of low-stock inventory positions, each row carrying a per-row recommendation generated by an admin-authored `GenAiPromptTemplate`. Clicking the Grid's **Transfer/Optimize** button on a row launches a Flow that calls an Apex invocable action, which evaluates compliance, finds the best source store, calculates a capped transfer quantity, and (on confirmation) executes the move atomically while writing a `Transfer_Log__c` audit record.

There is no LWC, no middleware, and no external service. Every component is platform-native. The prompt template itself is **not** packaged — Salesforce's `GenAiPromptTemplate` type requires server-generated hash identifiers, so admins create it manually in Prompt Builder following [Create the Prompt Template](setup/create-prompt-template.html).

## Key Constants at a Glance

The entire policy of the system is encoded in four constants in `InterStoreTransferService`:

| Constant | Value | What it controls |
|---|---|---|
| `TRANSFER_BUFFER_PCT` | `50` | Proposed transfer = 50% of source surplus above its safety stock |
| `MIN_DAYS_TO_EXPIRY` | `30` | Source candidates expiring within this window are excluded |
| `DEA_SCHEDULE_II` | `'II'` | Picklist value that triggers the compliance hard-stop |
| `PREVIEW_MAX_LENGTH` | `255` | `Recommendation_Preview__c` truncation cap (Grid column field type) |
